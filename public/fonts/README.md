# Font sources and licenses

All bundled fonts are licensed under the SIL Open Font License 1.1 (OFL).
The matching copyright and license notices are distributed beside the font files.
The site serves these assets locally and makes no Google Fonts requests at runtime.

| Files | Source | License notice |
| --- | --- | --- |
| `jetbrains-mono-latin.woff2` (variable, weights 100–800) | JetBrains Mono, distributed by Google Fonts | `JetBrains-Mono-OFL.txt` |
| `ibm-plex-sans-latin.woff2` (weights 400 and 700) | IBM Plex Sans, distributed by Google Fonts | `IBM-Plex-Sans-OFL.txt` |
| `ascii-rest-mono.woff2` | The JetBrains Mono glyph subset distributed by ascii.rest | `JetBrains-Mono-OFL.txt` |

Upstream references:

- [JetBrains Mono and its license](https://github.com/JetBrains/JetBrainsMono)
- [IBM Plex and its license](https://github.com/IBM/plex)
- [ascii.rest's fallback font documentation](https://github.com/bas3line/ascii#browser-support)

The OFL permits font embedding and redistribution with the required notices.
Keep the license files with these assets when deploying or redistributing the site.
System fallback fonts are supplied by the visitor's device and are not bundled here.
